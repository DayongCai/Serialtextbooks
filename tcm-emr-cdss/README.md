# 中医电子病历与临床决策支持（TCM Electronic Medical Record & Clinical Decision Support）

本目录为本书的 **GitBook 标准源码树**：`.gitbook.yaml` 为 space 配置，`SUMMARY.md` 为目录，每章一个 Markdown 页面，插图在 `.gitbook/assets/`。

体例：`# 第N章` / `## N.M 节` / `### N.M.K 小节`；正文为自然段；要点用 `> **要点**`；插图为 `<figure><img><figcaption>`；插表为管道表。

由 `tools/cm-gitbook-official.mjs --export` 生成，可被 `gitbook-to-excel --import` 反向导入为 Excel。
